# Forks and variants

If you adapt starccm-mcp, please publish your version as a GitHub fork of
<https://github.com/RHerAle/starccm-mcp> and open a pull request that adds one
line here: the link, what it changes and the STAR-CCM+ version it was tested
with. The licence already requires every variant to keep the attribution to this
project and to be marked as a modified version (see NOTICE); listing it here is a
request, not a condition, and helps other users find it.
